# 差旅报销材料清单（评测用样本，非真实制度）

本文件是 `tools/kb_eval.py` 要点完整性题（KB09）的固定语料。删掉下面任何一项都会让它判红。
判据理由写在 `tools/kb_eval_cases.json` 里 —— 语料正文会被索引进检索，
把「答案该含哪几项」写在这里等于给模型递答案。

## 一、差旅报销需要提交的材料

- 出差申请单：出发前经直属主管签批，事后补签视为违规。
- 住宿费发票：每晚一张，须含入住人姓名与房型明细。
- 交通票据：高铁票、机票与登机牌一并提交，缺一不受理。
- 行程说明单：注明每日起止城市与事由，与票据一一对应。
- 费用明细表：逐笔填写并合计，与所附票据金额一致。
